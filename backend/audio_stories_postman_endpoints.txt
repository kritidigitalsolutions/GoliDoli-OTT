
         GoliDoli OTT — Audio Stories API Test Suite (Postman)

========================================================================
BASE URL
========================================================================

http://localhost:5000

(Change to your production URL when testing on the live server)

========================================================================
AUTHENTICATION — GET YOUR TOKENS FIRST
========================================================================

1. Admin Login
   - Method  : POST
   - URL     : http://localhost:5000/api/admin/auth/login
   - Body (JSON):
     {
       "email": "admin@gmail.com",
       "password": "123456"
     }
   - Response: Returns a JWT "token". Save it as <admin_token>.

2. User Login (OTP Flow — Step 1: Send OTP)
   - Method  : POST
   - URL     : http://localhost:5000/api/auth/send-otp
   - Body (JSON):
     {
       "phone": "+919999999999"
     }

3. User Login (OTP Flow — Step 2: Verify OTP)
   - Method  : POST
   - URL     : http://localhost:5000/api/auth/verify-otp
   - Body (JSON):
     {
       "phone": "+919999999999",
       "otp": "1234"
     }
   - Response: Returns a JWT "token". Save it as <user_token>.

ADMIN — AUDIO STORIES  (/api/admin/audio-stories)
========================================================================

All admin requests require the header:
  Authorization: Bearer <admin_token>

NOTE: Endpoints that accept files use multipart/form-data.
      Set Body type to "form-data" in Postman for those.

------------------------------------------------------------------------
1. Create Audio Story
   - Method       : POST
   - URL          : http://localhost:5000/api/admin/audio-stories
   - Body type    : form-data
   - Fields:
       title         (text, REQUIRED)   e.g. "The Haunted Mansion"
       description   (text, optional)   Short description / synopsis
       language      (text, optional)   e.g. "Hindi", "English"
       categories    (text, optional)   JSON array string of category IDs
                                        e.g. ["64abc123...", "64def456..."]
       status        (text, optional)   "Draft" | "Published" | "Archived"
                                        Default: "Draft"
       isPremium     (text, optional)   "true" | "false"   Default: "false"
       priority      (text, optional)   Number e.g. "1" (for ordering)
       coverImage    (file, optional)   Image file (jpg/png)
       bannerImage   (file, optional)   Wide banner image (jpg/png)

   - Minimal JSON-only example (raw JSON, no file upload):
     {
       "title": "The Haunted Mansion",
       "description": "A terrifying tale set in an old crumbling mansion.",
       "language": "Hindi",
       "categories": ["<category_id>"],
       "status": "Published",
       "isPremium": "false",
       "priority": "1"
     }

------------------------------------------------------------------------
2. Get All Audio Stories (Admin)
   - Method  : GET
   - URL     : http://localhost:5000/api/admin/audio-stories

   Optional query params:
     ?status=Published
     ?status=Draft
     ?status=Archived
     ?search=haunted

   Examples:
     http://localhost:5000/api/admin/audio-stories?status=Published
     http://localhost:5000/api/admin/audio-stories?search=mansion

------------------------------------------------------------------------
3. Get Single Audio Story by ID
   - Method  : GET
   - URL     : http://localhost:5000/api/admin/audio-stories/<story_id>

------------------------------------------------------------------------
4. Update Audio Story
   - Method       : PATCH
   - URL          : http://localhost:5000/api/admin/audio-stories/<story_id>
   - Body type    : form-data (if uploading new images) OR raw JSON
   - Fields (all optional for update):
       title         (text)
       description   (text)
       language      (text)
       categories    (text)  JSON array string of category IDs
       status        (text)  "Draft" | "Published" | "Archived"
       isPremium     (text)  "true" | "false"
       priority      (text)  Number
       coverImage    (file)  Replaces old cover image
       bannerImage   (file)  Replaces old banner image

   - Example (JSON only):
     {
       "title": "The Haunted Mansion - Extended Edition",
       "status": "Published",
       "isPremium": "true"
     }

------------------------------------------------------------------------
5. Delete Audio Story
   - Method  : DELETE
   - URL     : http://localhost:5000/api/admin/audio-stories/<story_id>
   - Note    : Also deletes all associated episodes and their media
               files from Bunny CDN.

ADMIN — AUDIO EPISODES  (/api/admin/audio-episodes)
========================================================================

All admin requests require the header:
  Authorization: Bearer <admin_token>

NOTE: Endpoints that accept files use multipart/form-data.
      Set Body type to "form-data" in Postman for those.

------------------------------------------------------------------------
1. Get CDN Upload Configuration (for direct browser uploads)
   - Method  : GET
   - URL     : http://localhost:5000/api/admin/audio-episodes/upload-config
   - Note    : Returns Bunny CDN credentials for direct client-side uploads.

------------------------------------------------------------------------
2. Add Audio Episode
   - Method       : POST
   - URL          : http://localhost:5000/api/admin/audio-episodes
   - Body type    : form-data
   - Fields:
       title          (text, REQUIRED)  e.g. "Episode 1: The Dark Arrival"
       storyId        (text, REQUIRED)  MongoDB ID of the parent audio story
       episodeNumber  (text, REQUIRED)  Positive integer e.g. "1"
       duration       (text, REQUIRED)  Duration in seconds e.g. "1800" (30 min)
       description    (text, optional)  Episode description
       status         (text, optional)  "Draft" | "Published" | "Archived"
       isPremium      (text, optional)  "true" | "false"
       audio          (file, REQUIRED*) Audio file (.mp3, .wav, etc.)
                                        *OR pass audioUrl as text if already on CDN
       audioUrl       (text, optional)  CDN URL if not uploading audio file directly
       thumbnail      (file, optional)  Episode thumbnail image

   - Minimal example (form-data):
       title          -> "Episode 1: The Dark Arrival"
       storyId        -> "<story_id>"
       episodeNumber  -> "1"
       duration       -> "1800"
       status         -> "Published"
       audio          -> [select your .mp3 file]

------------------------------------------------------------------------
3. Get Episodes for a Story (Admin)
   - Method  : GET
   - URL     : http://localhost:5000/api/admin/audio-episodes?storyId=<story_id>
   - Note    : storyId query param is REQUIRED.

   Example:
     http://localhost:5000/api/admin/audio-episodes?storyId=64abc12345def678

------------------------------------------------------------------------
4. Update Audio Episode
   - Method       : PATCH
   - URL          : http://localhost:5000/api/admin/audio-episodes/<episode_id>
   - Body type    : form-data (if uploading new files) OR raw JSON
   - Fields (all optional for update):
       title          (text)
       episodeNumber  (text)  Positive integer
       duration       (text)  Duration in seconds
       description    (text)
       status         (text)  "Draft" | "Published" | "Archived"
       isPremium      (text)  "true" | "false"
       audio          (file)  Replaces old audio file on CDN
       thumbnail      (file)  Replaces old thumbnail on CDN

   - Example (JSON only):
     {
       "title": "Episode 1: The Dark Arrival (Remastered)",
       "status": "Published",
       "isPremium": "true"
     }

------------------------------------------------------------------------
5. Delete Audio Episode
   - Method  : DELETE
   - URL     : http://localhost:5000/api/admin/audio-episodes/<episode_id>
   - Note    : Also deletes the audio file and thumbnail from Bunny CDN.

USER — AUDIO PROGRESS  (/api/audio-progress)
========================================================================

All endpoints require user authentication:
  Authorization: Bearer <user_token>

------------------------------------------------------------------------
1. Save / Update Listening Progress
   - Method  : POST
   - URL     : http://localhost:5000/api/audio-progress
   - Headers : Authorization: Bearer <user_token>
   - Body (JSON):
     {
       "episodeId": "<episode_id>",
       "progressSeconds": 360,
       "durationSeconds": 1800
     }
   - Required fields:
       episodeId       MongoDB ID of the audio episode
       progressSeconds Current position in seconds (must be >= 0)
       durationSeconds Total duration in seconds (must be > 0)
   - Note: progressSeconds cannot exceed durationSeconds.
           Call this periodically while the user is listening.

------------------------------------------------------------------------
2. Get Episode Progress
   - Method  : GET
   - URL     : http://localhost:5000/api/audio-progress/<episode_id>
   - Headers : Authorization: Bearer <user_token>
   - Note    : Returns the saved listening progress for a specific episode
               for the currently authenticated user.

------------------------------------------------------------------------
3. Get Continue Listening List
   - Method  : GET
   - URL     : http://localhost:5000/api/audio-progress/continue
   - Headers : Authorization: Bearer <user_token>
   - Note    : Returns episodes the user has started but not completed.
               Use for "Continue Listening" section on home screen.

------------------------------------------------------------------------
4. Mark Episode as Completed
   - Method  : POST
   - URL     : http://localhost:5000/api/audio-progress/<episode_id>/complete
   - Headers : Authorization: Bearer <user_token>
   - Body    : (empty — no body needed)
   - Note    : Marks the given episode as fully listened/completed for
               the authenticated user.

========================================================================
IMPORTANT NOTES
========================================================================

- Replace <story_id>, <episode_id>, <category_id> with actual MongoDB
  ObjectIds from your database responses.

- For file uploads (audio, coverImage, bannerImage, thumbnail):
  Set Postman body type to "form-data" and use the file picker.

- Status values accepted: "Draft" | "Published" | "Archived"

- isPremium in form-data must be a string: "true" or "false"

- Number fields (duration, episodeNumber, priority, progressSeconds,
  durationSeconds) can be sent as text strings in form-data.

- Admin token expires — re-login to get a new one.

- The GET /api/admin/audio-episodes endpoint REQUIRES storyId as a
  query parameter. Without it, the API returns a 400 error.
